# Free & Open Source Writing Software for Novelists

> Find free tools for drafting, outlining, organising scenes and building long-form manuscripts.

`10 tools` &nbsp;&middot;&nbsp; `v1.3.1` &nbsp;&middot;&nbsp; `updated 2026-09-11` &nbsp;&middot;&nbsp; `9 open source`

[&larr; back to the index](../README.md)

If you need free novel writing software for a long manuscript, a normal word processor can quickly turn chapters, scenes and notes into one giant wall of text.

The strongest options here split into a few camps. novelWriter, Manuskript and bibisco are built around structured novel projects, where scenes, characters and outline live beside the prose. FocusWriter and Ghostwriter go the other way and strip everything back to the typing surface. oStorybook and novelibre are organisers first, useful when you want detailed control over scenes, characters and story structure - novelibre pairs its outline tree with LibreOffice Writer for the actual writing.

There are also broader writing tools such as Zettlr that work well for novelists who prefer Markdown and flexible files. This list favours tools whose core writing workflow is genuinely free, with open-source projects given priority and important limitations called out - including two entries whose websites were unreachable when this list was last checked.

## How these were chosen

- Free for core novel-writing use, without an expiring trial or a paywall on the basic writing workflow.
- Open-source projects are included only where a public repository and recognised open-source licence could be established; yWriter is the deliberate freeware exception.
- Current project activity, release status and platform availability were checked against official project sites and public source repositories where available.
- No affiliate or aggregator links: the `url` field points to the project's own homepage, while `repo` points to its source repository.
- Entries with unusually old releases or weaker maintenance signals are labelled plainly instead of being presented as equally current choices.

## Details

### 1. novelWriter

**Platforms** Windows, Linux, macOS &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2018  
[Homepage](https://novelwriter.io/) &nbsp;&middot;&nbsp; [Source](https://github.com/saga-soft/novelWriter)

Novelists who want a clean structured editor built around plain-text project files.

**Good** &mdash; Organises large projects into documents, folders, notes and metadata; Manuscript build tools can export polished documents; Plain-text storage keeps projects portable and resilient

**Less good** &mdash; macOS DMG releases were discontinued from 2026.1; Its Markdown-like workflow is less suitable for writers who want a rich-text-first editor

This is one of the strongest dedicated open-source choices in the list and is the clearest alternative to Manuskript for writers who value a simple project structure. The project is actively maintained, with stable 2026 releases and a separate beta track.

### 2. Quoll Writer

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** Apache-2.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2011  
[Homepage](https://quollwriter.com/) &nbsp;&middot;&nbsp; [Source](https://github.com/garybentley/quollwriter)

Writers who want a feature-rich novel workspace while keeping the interface focused on the text.

**Good** &mdash; Includes writing-focused tools such as goals, projects and story assets; Works across Windows, macOS and Linux; Project encryption and an activity log are available

**Less good** &mdash; The public repository and website do not present matching version information; Java-based desktop software feels more old-school than newer writing apps; quollwriter.com has not responded since around August 2026 (last good Internet Archive capture 7 June 2026) and the last commit was May 2025. There are no built downloads on GitHub either - all 30 releases are source tags with no attached files - so getting it running now means building from source with Java and Ant. Treat the project as dormant.

Quoll Writer is a close rival to novelWriter, but it takes a more feature-heavy desktop-app approach. The official site currently advertises version 3 and describes the software as free and open source, while the public GitHub README still references stable 2.4, so version details are worth checking before deployment.

### 3. FocusWriter

**Platforms** Windows, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2008  
[Homepage](https://gottcode.org/focuswriter/) &nbsp;&middot;&nbsp; [Source](https://github.com/gottcode/focuswriter)

Novelists who mainly need distraction-free drafting rather than elaborate story databases.

**Good** &mdash; Fullscreen writing interface keeps controls out of the way; Supports daily goals and live writing statistics; Themes, sounds and portable mode make the drafting environment highly customisable

**Less good** &mdash; It provides less scene, character and plot organisation than dedicated novel tools; The developer stopped shipping official macOS binaries in 2020; Mac users must build it themselves from source with Qt and CMake

FocusWriter is the lightweight choice here. It pairs well with a separate outlining or notes system and is a particularly good fit for writers who already know their story and mainly need a calm drafting environment. Officially supported platforms are now Windows and Linux only.

### 4. oStorybook

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** GPL-2.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2013  
[Homepage](https://ostorybook.eu/) &nbsp;&middot;&nbsp; [Source](https://framagit.org/ostorybook/ostorybook6)

Authors who want detailed control over characters, locations, scenes, timelines and story relationships.

**Good** &mdash; Dedicated data views for characters, locations, scenes and other story elements; Supports structured planning from draft through finished work; Current releases are available for Windows, macOS and Linux

**Less good** &mdash; Requires Java; The interface and terminology can feel more database-like than a modern minimalist writing app

oStorybook is a specialist story-management tool rather than just a text editor. Its current 6.x line is actively developed, making it one of the better choices for writers who want extensive story-structure tooling without paying for a proprietary suite.

### 5. yWriter

**Platforms** Windows, Android, iOS, macOS &nbsp;&middot;&nbsp; **Licence** Freeware &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2002  
[Homepage](https://www.spacejock.com/yWriter.html)

Windows-based novelists who want established chapter-and-scene management without paying for the software.

**Good** &mdash; Breaks novels into chapters and scenes; Tracks characters and scene-level information; The Windows edition is free without a subscription or trial limit

**Less good** &mdash; Closed source; The Windows version is established, but the Mac edition is described by the developer as still in progress; spacejock.com has returned a server error across the whole domain since at least 5 September 2026, confirmed by the Internet Archive, and it is the only place yWriter is distributed. Nothing suggests the project has ended, but there is currently no way to download it.

yWriter is the main freeware exception in this list because its core novelist workflow is genuinely free and its author continues to publish updates. Registration is optional support for the developer rather than a requirement to use the program.

### 6. Zettlr

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2017  
[Homepage](https://www.zettlr.com/) &nbsp;&middot;&nbsp; [Source](https://github.com/Zettlr/Zettlr)

Novelists who prefer Markdown files, fast search and a flexible research-to-manuscript workflow.

**Good** &mdash; Powerful full-text search across large collections of Markdown files; Exports through Pandoc and supports professional publishing workflows; Works well for combining manuscript material, notes and research

**Less good** &mdash; Not purpose-built around chapters, scenes and character databases; The broader feature set can feel excessive for writers who only want a distraction-free novel editor

Zettlr is the broadest tool in the list, not a conventional novel-writing app. It earns a place because its Markdown-based project model, search and export pipeline can work extremely well for authors managing a manuscript alongside substantial research.

### 7. Manuskript

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2015  
[Homepage](https://www.theologeek.ch/manuskript/) &nbsp;&middot;&nbsp; [Source](https://github.com/olivierkes/manuskript)

Writers who want outlining, character management and scene-based planning in one open-source application.

**Good** &mdash; Combines outlining with character and story organisation; Designed specifically as a writing tool rather than a general notes app; Available as free software under the GPL

**Less good** &mdash; The latest tagged release is 0.17.0, released in June 2025; The project still describes itself as being in early development, so users may encounter rough edges

Manuskript remains a useful structured-writing option, but its maintenance story is much weaker than novelWriter or oStorybook. It is best treated as a capable open-source choice for writers willing to tolerate an older release and occasional unfinished areas.

### 8. bibisco Community Edition

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2014  
[Homepage](https://bibisco.com/) &nbsp;&middot;&nbsp; [Source](https://github.com/andreafeccomandi/bibisco)

Novelists who want a character-and-structure-heavy workflow with a dedicated manuscript workspace.

**Good** &mdash; Organises chapters and scenes while tracking characters and story structure; Provides multiple export formats including PDF, DOCX and TXT in the community codebase; The Community Edition is openly licensed under the GPL

**Less good** &mdash; Advanced features are reserved for the paid Supporters Edition; The public GitHub repository's newest tagged release is still 2.2.0 from May 2020, even though the commercial product has since moved on to version 5, so the open-source tag history lags years behind what is actually sold and installed; The Community Edition's last commit was September 2024; active development has moved to the paid Supporters Edition

bibisco is a genuine open-source novel-writing project, but it uses a Community Edition/Supporters Edition split. The free Community Edition still covers core novel organisation and writing, so it qualifies, with the paid feature boundary made explicit. Treat the GitHub repository as a historical reference rather than a build target for the current release; the maintainer has not published a newer tagged source snapshot alongside the 3.x/4.x/5.x product releases.

### 9. Ghostwriter

**Platforms** Windows, macOS, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2015  
[Homepage](https://ghostwriter.kde.org/) &nbsp;&middot;&nbsp; [Source](https://github.com/KDE/ghostwriter)

Novelists who draft in Markdown and want the interface to get out of the way

**Good** &mdash; Genuinely distraction-free: a focus mode that dims everything but the current sentence or paragraph, and a full-screen mode with no chrome at all; Live word count, reading time and a session goal in a status bar you can hide, so progress tracking does not cost you a second window; Plain Markdown files on disk with no project database, so the manuscript stays readable by anything and exports through Pandoc to EPUB, DOCX or PDF

**Less good** &mdash; An editor, not an organiser - there is no scene list, character sheet or corkboard, so structure has to live in your folder layout or a separate outline; Now a KDE application, so the Windows and macOS builds trail the Linux ones and are easiest to get through the Microsoft Store or a KDE binary factory build

Maintained under KDE since 2022 and shipped on the KDE Gear release cycle - the GitHub releases page stops at 2.1.6 in 2022 and looks abandoned, which it is not. Flathub carried 26.04.3 in July 2026, and Debian and Arch both package it. If you want FocusWriter's calm with Markdown files underneath instead of RTF, this is the closer fit.

### 10. novelibre

**Platforms** Windows, Linux &nbsp;&middot;&nbsp; **Licence** GPL-3.0 &nbsp;&middot;&nbsp; **Cost** Free &nbsp;&middot;&nbsp; **Established** 2023  
[Homepage](https://github.com/peter88213/novelibre) &nbsp;&middot;&nbsp; [Source](https://github.com/peter88213/novelibre)

Writers who want yWriter's structured chapter-and-scene planning but open source

**Good** &mdash; Breaks a novel into parts, chapters and sections with characters, locations, items and plot lines attached, all in one editable tree; The manuscript itself stays an ODT file you write in LibreOffice Writer, so the prose is never locked inside a proprietary project database; Actively developed with frequent releases and a genuinely thorough English and German user guide

**Less good** &mdash; It is an organiser bolted to LibreOffice or OpenOffice, not a writing app - you need one of those installed plus Python 3.7 or newer before it does anything; Windows and Linux only; the author describes macOS support as experimental. Installation is a .pyz download from the repository rather than a signed installer, and the project is small - 45 stars at the time of checking

The closest open-source answer to yWriter's way of working, and not by accident: the same author wrote much of the tooling around yWriter's file format. Worth knowing what it is before you download - the organiser holds the structure and metadata, LibreOffice Writer holds the words, and the two stay in sync.

## FAQ

**What is the best free novel writing software?**

For most novelists, novelWriter is the strongest starting point because it combines a purpose-built novel workflow with current development and a simple plain-text project model. oStorybook is a better fit when you want deeper story-structure and timeline management.

**Which free novel writing software is best for outlining?**

Manuskript and oStorybook are the most outline-oriented choices here. oStorybook leans heavily into characters, locations, scenes and relationships, while Manuskript combines outlining with a dedicated writing workflow.

**Is free novel writing software good enough for a full book?**

Yes. Several tools in this list are designed specifically for long-form projects, and novelWriter, Quoll Writer, oStorybook and yWriter can all manage work at book scale. The main trade-off is usually interface polish or advanced export features, not whether you can draft a complete manuscript.

**Which option is best for distraction-free writing?**

FocusWriter is the simplest choice when drafting itself is the priority. Quoll Writer also keeps the writing area central, but adds more project and story-management features.

**Can I use free novel writing software for publishing?**

Yes, although the publishing workflow differs by tool. novelWriter supports manuscript builds and DocX export, Zettlr can hand work off to Pandoc and other publishing pipelines, and several other entries support common document exports.
