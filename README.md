## How these lists are made

Most "best free software" round-ups are affiliate pages with the word *free* in the title. These
are built to a different standard, and the standard is enforced by a validator rather than by
good intentions.

**What gets in:**

- **Genuinely free for its core purpose.** No expiring trial, no daily cap, no file-size limit,
  no watermark, no account required to save your own work. A tool that stops working on the
  third document is a trial, not a free tool, and it is not listed.
- **A stated licence.** Open source entries name an OSI-recognised licence and link the
  repository that proves it. Freeware is labelled freeware, never dressed up as open source.
- **At least one honest downside.** Every entry has a downsides field and it is never empty. A
  list where nothing has a drawback is an advertisement.

**What the build refuses to publish:**

- an entry whose cost is anything but free for core use
- an open source claim with no repository, or a licence not on the OSI list
- any link carrying a tracking or affiliate parameter
- an entry with no downsides listed
- a list with fewer than eight entries

**No affiliate links, ever.** Not on any entry, not anywhere in this repository. The build
rejects URLs carrying tracking or affiliate parameters, so it is not a promise you have to take
on trust. Everything covered here is free or open source, so there is nothing to earn a
commission on in the first place.

## How many tools per list

There is no cap. Lists aim for at least ten, and there is no reason to discard a good eleventh
tool to keep a round number. Anything that clears every rule but is too niche, too rough or too
new to recommend first goes in **Also consider** — validated exactly as strictly, presented
more lightly.

## Corrections

Software changes. A tool that was free last year may not be free now, a project may be
archived, a licence may change.

If you find something wrong, open a correction issue. Include a link to the source — the
project's own page or repository is ideal. Corrections with a source get fixed straight away.

Each entry carries a last-checked date. That date means a human opened the link and confirmed
it on that day. It is not automated, and it is not a guess.
